# Plan: Autonomous Cute Shooter Reinvention

## Objective
Transform the web game into a highly charming, overwhelmingly cute shooter that completely breaks away from the traditional Metal Slug formula. Deliver cute/charming visuals, autonomous gameplay loop, 15+ second automated Playwright playtest verification, visual proof screenshots, 100% green unit/E2E test suite, and verified production deployment to Vercel via `origin/main`.

## Methodology: Project Pattern & Swarm Hierarchy
1. **Phase 0: Parallel Survey (3 Explorers)**
   - Explorer 1 (Art/Render): Investigate `src/render/`, `src/assets/`, canvas drawing, sprite generation, palettes, and plan the cute/kawaii/chibi visual aesthetic.
   - Explorer 2 (Core Mechanics/Loop): Investigate `src/core/` (GameLoop, PlayerController, enemies, weapons, projectiles, collisions) and design a novel, fun, non-linear gameplay loop.
   - Explorer 3 (Tests & CI/Deployment): Investigate `tests/`, Playwright configuration, artifacts directory, build scripts, git status, and Vercel setup.

2. **Phase 1: Milestone M1 — Overwhelmingly Cute & Charming Art Overhaul**
   - Direct iteration loop: Explorer -> Worker -> Reviewers (2) -> Challengers (2) -> Forensic Auditor -> Gate.
   - Replace gritty arcade art with pastel/kawaii sprites, cute effects, candy/bubble/star particles, friendly UI.

3. **Phase 2: Milestone M2 — Autonomous Gameplay Reinvention (Novel Core Loop)**
   - Direct iteration loop: Explorer -> Worker -> Reviewers (2) -> Challengers (2) -> Forensic Auditor -> Gate.
   - Implement the reinvented core loop (e.g. cute arena bubble/star blossom blaster, dynamic pet companion or candy drop-combo system).

4. **Phase 3: Milestone M3 — Automated Playtesting & E2E Hardening**
   - 15+ second automated Playwright continuous playtest with 0 JS errors.
   - High-fidelity visual screenshots captured in `artifacts/cute_reinvention/`.
   - 100% green Vitest and Playwright test suites.

5. **Phase 4: Milestone M4 — Git Commit, Push & Vercel Deployment**
   - Commit changes, push to `origin/main`.
   - Verify Vercel deployment status and ensure live production environment is healthy.

6. **Phase 5: Independent Victory Audit & Final Presentation**
   - Forensic verification and comprehensive report to parent/user.
