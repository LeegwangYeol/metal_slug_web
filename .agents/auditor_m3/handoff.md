## 3. Adversarial Challenges & Caveats

### Challenge 1: Brittle Assertion Bound in `hitbox_dodge.spec.ts:220` [Medium]
- **Observation**: In Test 1 of `tests/e2e/hitbox_dodge.spec.ts:220`:
  ```typescript
  expect(minSeparationObserved).toBeGreaterThanOrEqual(12.0);
  expect(minSeparationObserved).toBeLessThanOrEqual(20.0);
  ```
  During empirical stress runs, because keyboard input is driven in real-time against an asynchronous browser loop with sub-pixel kinematic drift, `minSeparationObserved` occasionally recorded values between $10.2\text{px}$ and $11.0\text{px}$.
- **Impact**: When this occurs, the test fails on `expect(minSeparationObserved).toBeGreaterThanOrEqual(12.0)` even though the player successfully dodged the enemy without taking damage.
- **Root Cause**: The physical touch boundary is $r_{\text{player}} + r_{\text{enemy}} = 22.0\text{px}$. A separation of $10.2\text{px}$ is still outside physical contact ($d = 32.2\text{px}$) and far inside the old phantom damage radius ($45\text{px}$). The assertion `>= 12.0` is artificially narrow.
- **Mitigation Recommendation for Worker/Next Milestone**: Loosen the assertion lower bound from `>= 12.0` to `> 0.0` or `>= 5.0` (verifying near-miss clearance without collision).

### Challenge 2: Ephemeral WebServer Disconnect on Test Failure [Low]
- **Observation**: If a test in Playwright fails when using the configured ephemeral `webServer` command, Playwright's child process lifecycle may close the preview server before teardown completes, resulting in subsequent tests logging `net::ERR_CONNECTION_REFUSED at http://localhost:4173/`.
- **Mitigation**: When running full suites, ensuring a pre-launched preview server (`npm run preview`) or using `CI=1` prevents cascading connection refused errors.
